### March 2020

## Problem

Ticket Brokers need a marketplace where they can easily manage, analyze, buy, and sell inventory. Currently, these tasks are hidden behind obstacles in the UI that prohibit the user from achieving a productive and efficient workflow.

## Solution

Create a marketplace that allows the user to improve search functionality, streamline their ability to bulk edit ticket groups, offer a customizable workflow, and allow advanced searching for their inventory.

![](https://cdn.prod.website-files.com/61f087014bd85c3adea3643a/61f4196c8b75b1992377beed_Mask%20Group%20(1).jpg)

### Process

**1. Improve Search Functionality**

A typical user has thousands of events in their inventory. They need an easy way to search for events by specific details - such as venue, sections, seat, etc.

Default View: The Open Drawer

Searching for an event is the primary action our users take in the marketplace. Because of this, my team and I decided that leaving the drawer open by default would help our users quickly jump into their workflow.

![](/images/tm1.png)

Search by Multiple Fields

Since our users value customization and flexibility when it comes to managing their inventory, we added the ability to conduct an advanced search. Not only can the user search by a variety of properties, but they can view multiple events at the same time.

To search for more than one event, the user can select the '+' next to a given field.

![](/images/tm2.gif)

**2. Streamline Ability To Edit Multiple Ticket Groups**

Previously, editing single and multiple ticket groups were treated as two completely different actions and were placed in different parts of marketplace. Since these actions are aiming to achieve the same goal, my team and I streamlined this by dynamically changing the content that is editable based on how many ticket groups are selected.

![](/images/tm3.gif)

**3. Offer a Customizable Workflow**

Working with thousands of ticket groups can be tedious. Allowing the user to create their own workflow is important to our users, so I incorporated features that would allow them to do so.

Expanding & Collapsing Event Headers

This view allows user to show and hide content, so they can easily focus on particular events at once.

![](/images/tm4.gif)

Customizable Views

The user can decide which columns to show and hide. They can also decide how compact their view will be.

![](/images/tm5.png)

![](/images/tm6.png)

**4. Advanced Search for Other Inventory**

Users can easily toggle their view from ‘my inventory’ to the marketplace, where they can browse and purchase additional inventory.

Our users know at least one piece of criteria to the events that they’re looking for. To reduce cognitive load and loading time, the default view for the marketplace is empty, with the drawer spilled open. This way, they can build up a custom search, rather than narrowing down from a lengthy list of events.
